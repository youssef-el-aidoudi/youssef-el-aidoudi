## Selected projects

### [Text-Classification-Lab](https://github.com/youssef-el-aidoudi/Text-Classification-Lab) · [try it live ↗](https://youssef-el-aidoudi.github.io/Text-Classification-Lab/)

A spam detector trained in Python that runs **in your browser**. Type a message and watch which words tip the decision, with their exact weights.

Four models compared on 5,572 SMS. The best one blocks 134 spams out of 149 while wrongly flagging only 6 real messages — the trade-off matters more than the headline accuracy. A second part trains a PyTorch MLP on IMDb reviews and measures what each hyperparameter is really worth.

The trained model is exported to JSON and re-implemented in JavaScript; the port was checked against scikit-learn on all 1,115 test messages and agrees on 100% of them.

`scikit-learn` `PyTorch` `TF-IDF` `pandas` `JavaScript` `GitHub Pages`

### [real-time-weather-platform](https://github.com/youssef-el-aidoudi/real-time-weather-platform)

A near-real-time ELT pipeline that collects weather data for five French cities every five minutes, from the API call to the dashboard. Double deduplication at ingestion and in staging, and a bootstrap service that backfills the last 24 hours on startup.

`Airflow` `dbt` `PostgreSQL` `Superset` `Docker Compose` `Redis`

### [ChessMate](https://github.com/youssef-el-aidoudi/lichess-2025-2026)

A chess analysis platform built on Lichess open data, with a medallion ETL architecture (bronze / silver / gold) in PostgreSQL and a hybrid cheat-detection score combining a gradient-boosting model, Stockfish evaluation and behavioural telemetry.

`Spring Boot` `React` `PostgreSQL` `RabbitMQ` `FastAPI` `XGBoost` `Docker` `Grafana`

### [GameMetrics](https://github.com/youssef-el-aidoudi/GameMetrics)

A game analytics platform on MongoDB: flexible game documents with embedded reviews, engagement metrics computed in Python and written back to the database, and an interactive dashboard.

`MongoDB` `Python` `Streamlit` `Plotly`
